# 长征跳一跳 · Long March Jump

长征历史知识问答 × 跳一跳玩法的网页小游戏，静态单页，部署在 GitHub Pages。

## 玩法

- 按住屏幕 / 空格蓄力，松开跳跃：蓄力越久跳得越远
- 跳上"红色问答块"弹出长征历史题目，题目与当前路线站点关联（遵义站考遵义会议、泸定桥站考飞夺泸定桥…），答对得星火 ×15，答错展示正确答案与讲解
- 跳空不失败，落回目标格继续赶路；失误只记录士气 -1，作为这一路的足迹
- 长征没有失败：无论怎样，都能走到会宁会师，游戏只有胜利结局
- 方块沿途对应长征路线：瑞金 → 湘江 → 遵义 → 赤水 → 金沙江 → 泸定桥 → 夹金山 → 草地 → 会宁
- 走完全程到达"会宁会师"即通关

## 本地运行

浏览器直接打开 `index.html` 即可，无需安装任何依赖。
